# Service-colour hallway test

This is the Phase 9 observation sheet for the map-only acceptance test. Run it
with the fixture scenes in `ServiceColourFixtures.stories.tsx`, in each theme
and colour mode. Do not explain the ramp or offer route advice while observing.

## Prompt

Ask each rider, in order:

1. “Where’s the pain?”
2. “Where’s relief coming from?”
3. “Would you wait here or walk?”

Record the rider’s unprompted answer, the scene/theme/mode, and whether the
answer came from the map paint, chevrons, labels, or another surface. The
observer must not correct or coach the rider during the three answers.

## Verdict

Pass only when all five riders can identify the painful stream, identify the
direction of relief, and state a wait/walk choice without computed advice or
observer coaching. Attach the completed sheet to the review before marking the
run story complete.
